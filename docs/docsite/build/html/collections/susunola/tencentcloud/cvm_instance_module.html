susunola.tencentcloud.cvm_instance module – Manage Tencent Cloud CVM instances

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.cvm_instance.

New in susunola.tencentcloud 0.4.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

  • Return Values

Synopsis

  • Create, update, start, stop and terminate Tencent Cloud CVM instances through the cvm.v20170312 API.

  • This module is idempotent. Running it twice leaves the instance unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

count_tag

dictionary

Tag key/value pairs identifying the pool of instances managed through exact_count, for example role=web.

Matching uses one tag:key instance filter per pair, combined with AND, so an instance must carry every pair to count towards the pool.

The tag must already be attached to the instances; tags passed in tags are attached at creation and therefore match on subsequent runs.

dry_run

boolean

When true, creation calls RunInstances with the API DryRun flag so the request is validated without creating an instance.

Only applies to creation; it is ignored once the instance exists.

Choices:

  • false ← (default)

  • true

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

exact_count

integer

Desired number of instances in the pool matched by count_tag.

When state=present and exact_count are both given, the module counts the instances matching count_tag and brings the pool to the requested size (fewer instances are created in one RunInstances call, extra instances are terminated oldest first).

When zones is also given, the created shortfall is spread across the listed availability zones as evenly as possible, with one RunInstances call per zone.

Mutually exclusive with instance_id; requires count_tag.

Instances that are already in the desired count are left untouched.

PREPAID instances are never terminated automatically; if a matched instance that would be removed is PREPAID the module fails instead.

hostname

string

Instance host name. Only applied at creation.

image_id

string

Image ID (img-xxxxxxxx) used to create the instance.

Required when the instance does not exist yet.

Only applied at creation; changing it on an existing instance fails with a message asking to recreate the instance.

instance_charge_type

string

Instance billing mode written to RunInstancesRequest.InstanceChargeType.

Choices:

  • "PREPAID"

  • "POSTPAID_BY_HOUR" ← (default)

instance_id

string

ID of an existing instance, e.g. ins-xxxxxxxx.

When given, the module operates on that instance; otherwise the instance is matched by instance_name through the instance-name filter and the first match is used.

instance_name

string

Display name of the instance.

Used to look up the instance when instance_id is not given, and as the desired name to enforce on an existing instance.

instance_type

string

Instance model, e.g. S5.MEDIUM2. See DescribeInstanceTypeConfigs for the available values.

Required when the instance does not exist yet.

On an existing instance a different value is applied with ResetInstancesType (instance resizing). The instance must be stopped first - change instance_type together with state=stopped, or stop it beforehand, otherwise the module fails with guidance. Resizing keeps the instance stopped; start it afterwards with state=running.

internet_charge_type

string

Network billing mode written to InternetAccessible.InternetChargeType.

Choices:

  • "BANDWIDTH_PREPAID"

  • "TRAFFIC_POSTPAID_BY_HOUR"

  • "BANDWIDTH_POSTPAID_BY_HOUR"

  • "BANDWIDTH_PACKAGE"

internet_max_bandwidth_out

integer

Maximum outbound public bandwidth in Mbps, written to InternetAccessible.InternetMaxBandwidthOut.

key_ids

list / elements=string

Key pair IDs associated with the instance at creation through LoginSettings.KeyIds.

password

string

Login password set at creation through LoginSettings.Password.

Mutually exclusive with key_ids on the API side; Windows instances do not support key pairs.

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

public_ip_assigned

boolean

Whether a public IP is assigned, written to InternetAccessible.PublicIpAssigned.

Only meaningful when internet_max_bandwidth_out is greater than 0.

Choices:

  • false

  • true

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

reset_password

boolean

When true, resets the login password of an existing instance with ResetInstancesPassword using the value of password.

Only applies with state=present; requires password. The module cannot read the current password, so every run with reset_password=true resets it and reports changed=true. Use it as an explicit one-shot action, not as a reconciliation flag.

Choices:

  • false ← (default)

  • true

retries

integer

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

Default: 5

role_arn

string

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

role_session_duration

integer

Validity of the temporary role credentials in seconds.

Default: 7200

role_session_name

string

Session name recorded for the assumed role.

Default: "ansible-tencentcloud"

secret_id

string

Tencent Cloud API secret ID.

Falls back to TENCENTCLOUD_SECRET_ID, then to the selected profile section in ~/.tencentcloud/default.configure.

secret_key

string

Tencent Cloud API secret key.

Falls back to TENCENTCLOUD_SECRET_KEY, then to the selected profile section in ~/.tencentcloud/default.configure.

security_group_ids

list / elements=string

Security group IDs bound to the instance.

On an existing instance the bindings are reconciled through ModifyInstancesAttribute, replacing the current set.

state

string

present creates the instance with RunInstances when it does not exist, and updates its name, security groups and tags when it does.

absent terminates the instance with TerminateInstances and waits until it is gone.

running starts a stopped instance with StartInstances and waits for the RUNNING state. The instance must already exist.

stopped stops a running instance with StopInstances and waits for the STOPPED state. The instance must already exist.

rebooted reboots a running instance with RebootInstances and waits for it to come back to the RUNNING state. The instance must already exist and be running; rebooting a stopped instance fails. Reboot is a one-shot action - every run with state=rebooted issues a reboot, so the module always reports changed=true.

Choices:

  • "present" ← (default)

  • "absent"

  • "running"

  • "stopped"

  • "rebooted"

subnet_id

string

Subnet ID (subnet-xxxxxxxx) the instance belongs to.

Only applied at creation; changing it on an existing instance fails with a message asking to recreate the instance.

subnet_ids

list / elements=string

Subnets used when creating instances spread across zones, one per zone in the same order, for example [subnet-az3, subnet-az4].

When the list is shorter than zones it is reused cyclically.

Requires zones; ignored otherwise.

tags

dictionary

Tags to apply to the instance as a dict, for example env=prod.

At creation the tags are bound through TagSpecification; on an existing instance they are reconciled through the tag service (ServiceType=cvm, ResourcePrefix=instance).

Existing tags not listed are removed; listed tags with a different value are updated. Requires the tencentcloud-sdk-python-tag package and the tag service to be enabled for the account.

Default: {}

timeout

integer

SDK HTTP request timeout in seconds.

Default: 60

token

string

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

user_agent

string

Value appended to the SDK User-Agent header so API usage can be attributed to this collection.

Default: "ansible-collection.susunola.tencentcloud"

vpc_id

string

VPC ID (vpc-xxxxxxxx) the instance belongs to.

Only applied at creation; changing it on an existing instance fails with a message asking to recreate the instance.

waiter_delay

integer

Interval in seconds between state polls while waiting.

Default: 5

waiter_timeout

integer

Maximum time in seconds to wait for the instance to reach the desired state (RUNNING after create, start or update; STOPPED after stop; gone after terminate).

Default: 120

zones

list / elements=string

Availability zones to spread the exact_count shortfall across, for example [ap-guangzhou-3, ap-guangzhou-4].

Each zone receives as close to an equal share of the created instances as possible; a zone with a zero share is skipped.

Only applies to exact_count pool creation; the zone of existing instances is never changed.

Notes

Note

  • Requires the tencentcloud-sdk-python-cvm package on the controller.

  • Tag reconciliation additionally requires tencentcloud-sdk-python-tag.

  • Uses the cvm.tencentcloudapi.com endpoint by default.

  • After a create or a start the module waits for the instance to reach RUNNING before returning; make sure the instance is able to run, a stopped instance would keep the waiter waiting until waiter_timeout. Updates on an existing instance never change the power state, so a stopped instance stays stopped and no wait is performed.

  • Image, VPC and subnet changes require recreating the instance; the module fails with a clear message when they drift on an existing instance instead of silently ignoring them.

  • Updates on an existing instance cover the name, security group bindings and tags via ModifyInstancesAttribute and the tag service, the instance model via ResetInstancesType (instance must be stopped) and the login password via ResetInstancesPassword when reset_password is set.

  • When exact_count creates several instances at once the platform appends a numeric suffix to instance_name, so the created instances are named web-01, web-02 and so on.

  • exact_count reads the pool through the tag:key filter; tags attached after creation through the console or the tag service are matched the same way as tags set through tags.

Examples

- name: Create a CVM instance
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: present
    instance_name: web-01
    image_id: img-xxxxxxxx
    instance_type: S5.MEDIUM2
    vpc_id: vpc-xxxxxxxx
    subnet_id: subnet-xxxxxxxx
    security_group_ids:
      - sg-xxxxxxxx
    key_ids:
      - skey-xxxxxxxx
    internet_charge_type: TRAFFIC_POSTPAID_BY_HOUR
    internet_max_bandwidth_out: 10
    public_ip_assigned: true
    tags:
      env: prod
      tier: web

- name: Validate a creation request without creating (API dry run)
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: present
    instance_name: web-01
    image_id: img-xxxxxxxx
    instance_type: S5.MEDIUM2
    dry_run: true

- name: Stop an instance
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: stopped
    instance_name: web-01

- name: Start an instance
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: running
    instance_name: web-01

- name: Reboot a running instance (one-shot action, always changed)
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: rebooted
    instance_name: web-01

- name: Stop the instance before resizing it
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: stopped
    instance_name: web-01

- name: Resize the stopped instance to a larger model
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: present
    instance_name: web-01
    instance_type: S5.LARGE4

- name: Reset the login password of an existing instance
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: present
    instance_name: web-01
    reset_password: true
    password: "N3w-Sup3r-Secret!"

- name: Terminate an instance
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: absent
    instance_name: web-01

- name: Scale the web pool to exactly 3 instances
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: present
    exact_count: 3
    count_tag:
      role: web
    instance_name: web
    image_id: img-xxxxxxxx
    instance_type: S5.MEDIUM2
    vpc_id: vpc-xxxxxxxx
    subnet_id: subnet-xxxxxxxx
    tags:
      role: web

- name: Scale the web pool to 5 instances spread across two zones
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: present
    exact_count: 5
    count_tag:
      role: web
    instance_name: web
    image_id: img-xxxxxxxx
    instance_type: S5.MEDIUM2
    vpc_id: vpc-xxxxxxxx
    zones: [ap-guangzhou-3, ap-guangzhou-4]
    subnet_ids: [subnet-az3, subnet-az4]
    tags:
      role: web

- name: Scale the web pool down to 1 (terminates the oldest extras)
  susunola.tencentcloud.cvm_instance:
    region: ap-guangzhou
    state: present
    exact_count: 1
    count_tag:
      role: web
