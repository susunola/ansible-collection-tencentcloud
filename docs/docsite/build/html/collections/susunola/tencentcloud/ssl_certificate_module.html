susunola.tencentcloud.ssl_certificate module – Manage Tencent Cloud SSL certificates

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.ssl_certificate.

New in susunola.tencentcloud 0.12.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

  • Return Values

Synopsis

  • Upload, rename, deploy and delete SSL certificates through the ssl.v20191205 API.

  • This module is idempotent. Running it twice leaves the certificate unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

  • A certificate is identified by certificate_id or by alias. When neither exists and cert_content is given, the certificate is uploaded.

  • Deployment pushes the certificate to cloud resources (e.g. CLB instances) with DeployCertificateInstance, closing the loop with the cert_id value of the certificate suboption of susunola.tencentcloud.clb_listener and susunola.tencentcloud.clb_rule.

Parameters

Parameter

Comments

alias

string

Name of the certificate, written to UploadCertificateRequest.Alias and ModifyCertificateAliasRequest.Alias.

cert_content

string

PEM content of the certificate public key, written to UploadCertificateRequest.CertificatePublicKey.

Required to upload a new certificate.

certificate_id

string

ID of an existing certificate, e.g. XXXX-XXXX-XXXX.

When given, the module operates on that certificate; otherwise it is matched by alias.

certificate_type

string

Type of the certificate, written to UploadCertificateRequest.CertificateType.

Choices:

  • "CA"

  • "SVR" ← (default)

deploy_instances

list / elements=string

IDs of the instances to deploy the certificate to (e.g. CLB load balancer IDs), written to DeployCertificateInstanceRequest. InstanceIdList.

Deployment is skipped when the list is empty.

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

private_key

string

PEM content of the certificate private key, written to UploadCertificateRequest.CertificatePrivateKey.

Required to upload a new certificate. The value is masked from output automatically.

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

project_id

integer

Project the certificate belongs to, written to UploadCertificateRequest.ProjectId.

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

resource_type

string

Resource type of deploy_instances, written to DeployCertificateInstanceRequest.ResourceType.

Default: "clb"

retries

integer

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

Default: 5

role_arn

string

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

role_session_duration

integer

Validity of the temporary role credentials in seconds.

Default: 7200

role_session_name

string

Session name recorded for the assumed role.

Default: "ansible-tencentcloud"

secret_id

string

Tencent Cloud API secret ID.

Falls back to TENCENTCLOUD_SECRET_ID, then to the selected profile section in ~/.tencentcloud/default.configure.

secret_key

string

Tencent Cloud API secret key.

Falls back to TENCENTCLOUD_SECRET_KEY, then to the selected profile section in ~/.tencentcloud/default.configure.

string

present uploads the certificate when it does not exist, renames it when alias differs, and deploys it when deploy_instances is given.

absent deletes the certificate.

Choices:

  • "present" ← (default)

  • "absent"

dictionary

Tags to apply to the certificate as a dict, for example env=prod.

Only applied at upload.

timeout

SDK HTTP request timeout in seconds.

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

user_agent

Value appended to the SDK User-Agent header so API usage can be attributed to this collection.

integer

Seconds to wait between state-polling attempts while waiting for a resource to reach its desired state.

Overall timeout in seconds for state polling before the module gives up and fails the task.

Notes

Note

  • Requires the tencentcloud-sdk-python-ssl package on the controller.

  • Keep private_key out of --check output; use no_log on the task or ANSIBLE_NO_LOG when the value must be masked.

Examples

- name: Upload a certificate and deploy it to a CLB instance
  susunola.tencentcloud.ssl_certificate:
    region: ap-guangzhou
    state: present
    alias: api-tls
    cert_content: "{{ lookup('ansible.builtin.file', 'api.crt') }}"
    private_key: "{{ lookup('ansible.builtin.file', 'api.key') }}"
    deploy_instances:
      - lb-xxxxxxxx
    resource_type: clb

- name: Reference the certificate from a CLB HTTPS listener
  susunola.tencentcloud.clb_listener:
    region: ap-guangzhou
    load_balancer_id: lb-xxxxxxxx
    port: 443
    protocol: HTTPS
    certificate:
      cert_id: "{{ cert.certificate_id }}"
      ssl_mode: MUTUAL

- name: Delete the certificate
  susunola.tencentcloud.ssl_certificate:
    region: ap-guangzhou
    state: absent
    alias: api-tls
