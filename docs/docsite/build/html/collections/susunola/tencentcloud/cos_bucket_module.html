susunola.tencentcloud.cos_bucket module – Manage Tencent Cloud COS buckets

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.cos_bucket.

New in susunola.tencentcloud 0.5.0

  • Synopsis

  • Parameters

  • Notes

Synopsis

  • Create, update, and delete Tencent Cloud Object Storage (COS) buckets.

  • COS is not part of the Tencent Cloud API 3.0 family; this module uses the qcloud_cos SDK (cos-python-sdk-v5 package) instead.

  • This module is idempotent. Running it twice leaves the bucket unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

acl

string

Canned ACL applied to the bucket. Applied at creation and reconciled on updates.

Choices:

  • "private" ← (default)

  • "public-read"

  • "public-read-write"

appid

string

Tencent Cloud account AppId used as the bucket name suffix.

When omitted, the AppId is resolved via the STS GetCallerIdentity API, which additionally requires the tencentcloud-sdk-python-sts package.

cors

list / elements=dictionary

List of CORS rules to configure on the bucket, replacing the full rule set (rules not listed are removed).

Each rule requires allowed_origins and allowed_methods; id, allowed_headers, expose_headers and max_age_seconds are optional.

When omitted, the CORS configuration is left unmanaged. Pass an empty list to remove every rule.

allowed_headers

list / elements=string

Headers allowed in preflight requests.

allowed_methods

list / elements=string / required

HTTP methods allowed, for example GET, PUT.

allowed_origins

list / elements=string / required

Origins allowed to make cross-origin requests, for example http://www.example.com or https://*.example.com.

expose_headers

list / elements=string

Headers exposed to the browser in the actual response.

id

string

Optional rule identifier.

max_age_seconds

integer

How long in seconds the browser caches the preflight result.

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

lifecycle

list / elements=dictionary

List of lifecycle rules to configure on the bucket, replacing the full rule set (rules not listed are removed).

Each rule is matched by prefix; a rule with an empty prefix applies to the whole bucket. At least one of expiration_days, transitions, noncurrent_version_transitions or abort_incomplete_multipart_upload_days must be set per rule.

When omitted, the lifecycle configuration is left unmanaged. Pass an empty list to remove every rule.

abort_incomplete_multipart_upload_days

integer

Abort incomplete multipart uploads this many days after initiation.

expiration_days

integer

Delete objects this many days after they are created.

Mutually exclusive with date-based expiration, which this module does not manage; a date-based rule on the bucket is reported as a change and rewritten as a day-based one.

id

string

Optional rule identifier.

noncurrent_version_transitions

list / elements=dictionary

Storage class transitions for noncurrent versions, each with noncurrent_days and storage_class.

Requires versioning to be enabled on the bucket.

noncurrent_days

integer / required

Days after a version becomes noncurrent before the transition applies.

storage_class

string / required

Destination storage class, for example STANDARD_IA or ARCHIVE.

prefix

string

Object key prefix the rule applies to, for example logs/.

When omitted the rule applies to the whole bucket.

status

string

Whether the rule is enabled.

Choices:

  • "enabled" ← (default)

  • "disabled"

transitions

list / elements=dictionary

Storage class transitions for current versions, each with days and storage_class.

days

integer / required

Days after creation before the transition applies.

storage_class

string / required

Destination storage class, for example STANDARD_IA, ARCHIVE or DEEP_ARCHIVE.

name

string / required

Name of the bucket without the AppId suffix, for example mybucket.

The module appends the account AppId to form the full bucket name <name>-<appid> that the COS API expects; a name already ending in -<appid> is used unchanged.

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

retries

integer

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

Default: 5

role_arn

string

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

role_session_duration

integer

Validity of the temporary role credentials in seconds.

Default: 7200

role_session_name

string

Session name recorded for the assumed role.

Default: "ansible-tencentcloud"

secret_id

string

Tencent Cloud API secret ID.

Falls back to TENCENTCLOUD_SECRET_ID, then to the selected profile section in ~/.tencentcloud/default.configure.

secret_key

string

Tencent Cloud API secret key.

Falls back to TENCENTCLOUD_SECRET_KEY, then to the selected profile section in ~/.tencentcloud/default.configure.

state

string

present creates the bucket if it does not exist and updates its ACL, versioning, CORS, lifecycle and tags to match the task.

absent deletes the bucket if it exists. Deleting a bucket that is not empty fails with a BucketNotEmpty error; empty it first.

Choices:

  • "present" ← (default)

  • "absent"

tags

dictionary

Tags to apply to the bucket as a dict, for example env=prod.

Uses native COS bucket tagging (put_bucket_tagging), not the Tencent Cloud tag service.

Existing tags not listed are removed; listed tags with a different value are updated.

Default: {}

timeout

integer

SDK HTTP request timeout in seconds.

Default: 60

token

string

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

user_agent

string

Value appended to the SDK User-Agent header so API usage can be attributed to this collection.

Default: "ansible-collection.susunola.tencentcloud"

versioning

boolean

Whether object versioning is enabled on the bucket.

When omitted, the versioning configuration is left unmanaged.

Choices:

  • false

  • true

waiter_delay

integer

Seconds to wait between state-polling attempts while waiting for a resource to reach its desired state.

Default: 5

waiter_timeout

integer

Overall timeout in seconds for state polling before the module gives up and fails the task.

Default: 120

Notes

Note

  • Requires the cos-python-sdk-v5 package on the controller.

  • role_arn is honoured; the temporary credentials obtained via STS AssumeRole additionally require the tencentcloud-sdk-python-sts package.

Examples

- name: Create a COS bucket
  susunola.tencentcloud.cos_bucket:
    region: ap-guangzhou
    state: present
    name: mybucket
    appid: "1300000000"
    acl: private
    versioning: true
    tags:
      env: prod

- name: Check whether the bucket would be updated (no changes applied)
  susunola.tencentcloud.cos_bucket:
    region: ap-guangzhou
    state: present
    name: mybucket
    appid: "1300000000"
    acl: public-read
  check_mode: true

- name: Delete a COS bucket
  susunola.tencentcloud.cos_bucket:
    region: ap-guangzhou
    state: absent
    name: mybucket
    appid: "1300000000"

- name: Configure CORS and lifecycle rules on a bucket
  susunola.tencentcloud.cos_bucket:
    region: ap-guangzhou
    state: present
    name: mybucket
    appid: "1300000000"
    cors:
      - id: web
        allowed_origins:
          - https://www.example.com
        allowed_methods: [GET, HEAD]
        allowed_headers: [x-cos-meta-test]
        expose_headers: [ETag]
        max_age_seconds: 600
    lifecycle:
      - id: logs-expire
        prefix: logs/
        expiration_days: 30
        transitions:
          - days: 7
            storage_class: STANDARD_IA
        abort_incomplete_multipart_upload_days: 7
      - id: archive-old
        prefix: archive/
        noncurrent_version_transitions:
          - noncurrent_days: 15
            storage_class: ARCHIVE
