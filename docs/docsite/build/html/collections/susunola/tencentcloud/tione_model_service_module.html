susunola.tencentcloud.tione_model_service module -- Manage Tencent Cloud TIONE online model service configuration

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.tione_model_service.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Examples

  • Return Values

Synopsis

  • Creates a service version and reconciles every configuration field reliably returned by DescribeModelService.

  • Existing resources require stable service_id. Create-only drift is rejected and must be deployed as a new version.

  • Use tione_model_service_state for operational start and stop.
