susunola.tencentcloud.eip module – Manage Tencent Cloud elastic IP addresses (EIP)

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.eip.

New in susunola.tencentcloud 0.4.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

  • Return Values

Synopsis

  • Allocate, update, associate, and release Tencent Cloud elastic IP addresses (EIP) through the VPC v20170312 Address APIs.

  • This module is idempotent. Running it twice leaves the resource unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

address_ip

string

Public IP address of an existing address, e.g. 1.2.3.4.

Used to match the address when eip_id is not given.

eip_id

string

ID of an existing address, e.g. eip-xxxxxxxx.

The address is matched by eip_id first, then by address_ip, then by name.

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

instance_id

string

Optional CVM instance ID, e.g. ins-xxxxxxxx, the address must be associated with.

When given, the address is associated with this instance, disassociating it from any other resource first.

When set to an empty string, the address is kept unassociated.

When omitted, the existing association is left untouched.

internet_charge_type

string

Network billing mode of the address.

Applied at allocation; on an existing address the module switches the mode with ModifyAddressInternetChargeType. Only BANDWIDTH_PREPAID_BY_MONTH and TRAFFIC_POSTPAID_BY_HOUR are interchangeable, and each address can switch at most twice.

Choices:

  • "BANDWIDTH_PACKAGE"

  • "BANDWIDTH_POSTPAID_BY_HOUR"

  • "BANDWIDTH_PREPAID_BY_MONTH"

  • "TRAFFIC_POSTPAID_BY_HOUR"

internet_max_bandwidth_out

integer

Outbound bandwidth cap of the address in Mbps.

Applied at allocation; on an existing address the module adjusts the bandwidth with ModifyAddressesBandwidth, which supports postpaid, prepaid and bandwidth-package addresses.

name

string

Name of the address. Applied at allocation and enforced with ModifyAddressAttribute on existing addresses.

When neither eip_id nor address_ip is given, the address is matched by name so that repeated runs stay idempotent. Address names are not unique; the first match wins.

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

retries

integer

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

Default: 5

role_arn

string

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

role_session_duration

integer

Validity of the temporary role credentials in seconds.

Default: 7200

role_session_name

string

Session name recorded for the assumed role.

Default: "ansible-tencentcloud"

secret_id

string

Tencent Cloud API secret ID.

Falls back to TENCENTCLOUD_SECRET_ID, then to the selected profile section in ~/.tencentcloud/default.configure.

secret_key

string

Tencent Cloud API secret key.

Falls back to TENCENTCLOUD_SECRET_KEY, then to the selected profile section in ~/.tencentcloud/default.configure.

state

string

present allocates the address if it does not exist and updates its name, tags, and instance association to match the task.

absent releases the address if it exists. When the address is still bound to an instance it is disassociated first, then released.

Choices:

  • "present" ← (default)

  • "absent"

tags

dictionary

Tags to apply to the address as a dict, for example env=prod.

Existing tags not listed are removed; listed tags with a different value are updated. Requires the tencentcloud-sdk-python-tag package and the tag service to be enabled for the account.

Default: {}

timeout

integer

SDK HTTP request timeout in seconds.

Default: 60

token

string

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

user_agent

string

Value appended to the SDK User-Agent header so API usage can be attributed to this collection.

Default: "ansible-collection.susunola.tencentcloud"

waiter_delay

integer

Seconds to wait between state-polling attempts while waiting for a resource to reach its desired state.

Default: 5

waiter_timeout

integer

Overall timeout in seconds for state polling before the module gives up and fails the task.

Default: 120

Notes

Note

  • Requires the tencentcloud-sdk-python-vpc package on the controller.

  • Tag reconciliation additionally requires tencentcloud-sdk-python-tag.

  • Uses the vpc.tencentcloudapi.com endpoint by default.

Examples

- name: Allocate an EIP
  susunola.tencentcloud.eip:
    region: ap-guangzhou
    state: present
    name: web-eip
    internet_charge_type: TRAFFIC_POSTPAID_BY_HOUR
    internet_max_bandwidth_out: 10
    tags:
      env: prod

- name: Allocate an EIP and associate it with a CVM instance
  susunola.tencentcloud.eip:
    region: ap-guangzhou
    state: present
    name: web-eip
    instance_id: ins-xxxxxxxx

- name: Make sure an EIP is not associated with anything
  susunola.tencentcloud.eip:
    region: ap-guangzhou
    state: present
    address_ip: 1.2.3.4
    instance_id: ""

- name: Release an EIP (disassociates it first when bound)
  susunola.tencentcloud.eip:
    region: ap-guangzhou
    state: absent
    eip_id: eip-xxxxxxxx
