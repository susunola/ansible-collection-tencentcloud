susunola.tencentcloud.cam_policy module -- Manage Tencent Cloud CAM policies

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.cam_policy.

New in susunola.tencentcloud 0.5.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

  • Return Values

Synopsis

  • Create, update, and delete Tencent Cloud CAM custom policies.

  • This module is idempotent. Running it twice leaves the policy unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

description

string

Description of the policy.

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

policy_document

any

Policy document as a JSON string or a dict. Required when creating a policy.

The document is compared semantically (parsed JSON), so formatting differences do not cause spurious changes.

policy_id

integer

ID of an existing policy. When given, the policy is looked up with GetPolicy and policy_name is treated as the desired name.

policy_name

string

Name of the policy. Required when state=present and the policy must be created. When policy_id is not given, the policy is matched by name within the type scope.

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

retries

integer

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

Default: 5

role_arn

string

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

role_session_duration

integer

Validity of the temporary role credentials in seconds.

Default: 7200

role_session_name

string

Session name recorded for the assumed role.

Default: "ansible-tencentcloud"

secret_id

string

Tencent Cloud API secret ID.

Falls back to TENCENTCLOUD_SECRET_ID, then to the selected profile section in ~/.tencentcloud/default.configure.

secret_key

string

Tencent Cloud API secret key.

Falls back to TENCENTCLOUD_SECRET_KEY, then to the selected profile section in ~/.tencentcloud/default.configure.

state

string

present creates the policy if it does not exist and updates its description, policy document and tags to match the task.

absent deletes the policy if it exists. Deleting a policy that is still attached to users, groups or roles fails; detach it first.

Choices:

  • "present" ← (default)

  • "absent"

tags

dictionary

Tags to apply to the policy as a dict, for example env=prod.

Existing tags not listed are removed; listed tags with a different value are updated. Requires the tencentcloud-sdk-python-tag package and the tag service to be enabled for the account.

Tags given at creation are passed to CreatePolicy directly; tag changes on an existing policy go through the tag service with service type cam and resource prefix policy.

Default: {}

timeout

integer

SDK HTTP request timeout in seconds.

Default: 60

token

string

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

type

string

Scope used when matching a policy by name. custom matches user-created policies (CAM scope Local); preset matches Tencent-managed preset policies (CAM scope QCS).

Only custom policies can be created, updated or deleted; preset policies are read-only.

Choices:

  • "custom" ← (default)

  • "preset"

user_agent

string

Value appended to the SDK User-Agent header so API usage can be attributed to this collection.

Default: "ansible-collection.susunola.tencentcloud"

waiter_delay

integer

Seconds to wait between state-polling attempts while waiting for a resource to reach its desired state.

Default: 5

waiter_timeout

integer

Overall timeout in seconds for state polling before the module gives up and fails the task.

Default: 120

Notes

Note

  • Requires the tencentcloud-sdk-python-cam package on the controller.

  • Tag reconciliation additionally requires tencentcloud-sdk-python-tag.

  • CAM is a global service. region is accepted (the shared argument spec requires it) but ignored; the global cam.tencentcloudapi.com endpoint is used.

Examples

- name: Create a custom CAM policy
  susunola.tencentcloud.cam_policy:
    region: ap-guangzhou
    state: present
    policy_name: app-read-only
    description: Read-only access to the app COS bucket
    policy_document:
      version: "2.0"
      statement:
        - action:
            - name/cos:GetObject
          effect: allow
          resource:
            - qcs::cos:ap-guangzhou:uid/1000000000:app-bucket-1000000000/*
    tags:
      env: prod

- name: Check whether the policy would be updated (no changes applied)
  susunola.tencentcloud.cam_policy:
    region: ap-guangzhou
    state: present
    policy_name: app-read-only
    description: Read-only access to the app COS bucket
  check_mode: true

- name: Delete a custom CAM policy
  susunola.tencentcloud.cam_policy:
    region: ap-guangzhou
    state: absent
    policy_name: app-read-only
