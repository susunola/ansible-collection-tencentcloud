susunola.tencentcloud.tdmysql_db_instance module -- Manage Tencent Cloud TDMysql instances

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.tdmysql_db_instance.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Examples

Synopsis

  • Creates, expands, upgrades, renames, isolates, recovers and permanently destroys TDMysql instances and reconciles security groups and renewal.

Examples

    zone: ap-guangzhou-3
    vpc_id: vpc-xxxxxxxx
    subnet_id: subnet-xxxxxxxx

    disk: 200
    storage_node_count: 3
    replications: 3
    storage_node_cpu: 4
    storage_node_memory: 16
    password: "{{ vault_tdmysql_password }}"
