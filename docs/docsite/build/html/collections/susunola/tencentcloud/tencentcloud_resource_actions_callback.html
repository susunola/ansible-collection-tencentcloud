susunola.tencentcloud.tencentcloud_resource_actions callback -- summarise Tencent Cloud API calls made during a play

Note

This callback plugin is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.tencentcloud_resource_actions.

New in susunola.tencentcloud 0.12.0

  • Callback plugin

  • Synopsis

  • Parameters

  • Examples

Callback plugin

This plugin is an aggregate callback. It adds additional console output next to the configured stdout callback. See Callback plugins for more information on callback plugins.

Synopsis

  • Aggregates the tc_api_calls audit trail that every module of this collection attaches to its result and prints a per-operation summary plus a JSON list at the end of the play.

  • Enabling this callback never changes module behaviour; it only reads the tc_api_calls key of task results.
