susunola.tencentcloud.nat_gateway module -- Manage Tencent Cloud NAT gateways

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.nat_gateway.

New in susunola.tencentcloud 0.12.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

Synopsis

  • Create, update and delete NAT gateways through the vpc.v20170312 API.

  • This module is idempotent. Running it twice leaves the gateway unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

address_count

integer

Number of EIPs to allocate for the gateway, written to CreateNatGatewayRequest.AddressCount.

Only applied at creation; the module does not allocate or release EIPs on an existing gateway.

deletion_protection_enabled

boolean

Whether the gateway is protected from deletion, written to ModifyNatGatewayAttributeRequest.DeletionProtectionEnabled.

When true and state=absent, the module removes the protection first, then deletes the gateway.

Choices:

  • false ← (default)

  • true

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

ignore_operation_risk

boolean

Skip the API safety check when deleting the gateway (e.g. while it still holds EIPs or translation rules), written to DeleteNatGatewayRequest.IgnoreOperationRisk.

Choices:

  • false ← (default)

  • true

internet_max_bandwidth_out

integer

Outbound bandwidth cap in Mbps, written to CreateNatGatewayRequest and ModifyNatGatewayAttributeRequest. Applies to the legacy bandwidth-billing gateway model.

max_concurrent_connection

integer

Maximum concurrent connections, written to CreateNatGatewayRequest.MaxConcurrentConnection.

Only applied at creation.

name

string

Name of the NAT gateway, written to CreateNatGatewayRequest.NatGatewayName and ModifyNatGatewayAttributeRequest.NatGatewayName.

nat_gateway_id

string

ID of an existing NAT gateway, e.g. nat-xxxxxxxx.

When given, the module operates on that gateway; otherwise the gateway is matched by name and vpc_id.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

Explicit EIPs to bind to the gateway, written to CreateNatGatewayRequest.PublicIpAddresses.

Only applied at creation.

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

retries

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

Default: 5

role_arn

string

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

Validity of the temporary role credentials in seconds.

Session name recorded for the assumed role.

Notes

Note

  • Requires the tencentcloud-sdk-python-vpc package on the controller.

  • NAT gateways are billed per hour while present; delete them as soon as they are no longer needed to avoid unnecessary charges.

Examples

- name: Create a NAT gateway with two auto-allocated EIPs
  susunola.tencentcloud.nat_gateway:
    region: ap-guangzhou
    state: present
    name: prod-nat
    vpc_id: vpc-aaaaaaaa
    address_count: 2
    internet_max_bandwidth_out: 100

- name: Enable deletion protection
  susunola.tencentcloud.nat_gateway:
    region: ap-guangzhou
    state: present
    name: prod-nat
    vpc_id: vpc-aaaaaaaa
    deletion_protection_enabled: true

- name: Delete a NAT gateway
  susunola.tencentcloud.nat_gateway:
    region: ap-guangzhou
    state: absent
    name: prod-nat
    vpc_id: vpc-aaaaaaaa
