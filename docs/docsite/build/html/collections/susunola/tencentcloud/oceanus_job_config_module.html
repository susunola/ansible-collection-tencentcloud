susunola.tencentcloud.oceanus_job_config module – Manage Tencent Cloud Oceanus job configuration versions

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.oceanus_job_config.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Examples

  • Return Values

Synopsis

  • Publishes a new immutable job configuration version only when managed fields differ from the latest version, and can explicitly delete a named historical version.
