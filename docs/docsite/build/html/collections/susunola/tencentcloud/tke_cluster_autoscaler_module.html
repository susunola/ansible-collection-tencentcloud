susunola.tencentcloud.tke_cluster_autoscaler module – Manage the cluster autoscaler options of a Tencent Cloud TKE cluster

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.tke_cluster_autoscaler.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

Synopsis

  • Reconcile the cluster-level autoscaler (CA) options of a TKE cluster through the tke.v20180525 API DescribeClusterAsGroupOption and ModifyClusterAsGroupOptionAttribute.

  • Only the options explicitly passed to the module are compared and written; options left unset are left untouched on the platform.

  • This module is idempotent. Running it twice with the same options reports changed=false on the second run.

  • Supports check mode; no API write happens in check mode, only reads.

Notes

Note

  • Requires the tencentcloud-sdk-python-tke package on the controller.

  • The autoscaler only acts on node pools created with EnableAutoscale=true; create those through tke_node_pool.

Examples

- name: Enable scale-down and tune the idle thresholds
  susunola.tencentcloud.tke_cluster_autoscaler:
    region: ap-guangzhou
    cluster_id: cls-xxxxxxxx
    is_scale_down_enabled: true
    scale_down_unneeded_time: 15
    scale_down_utilization_threshold: 40

- name: Switch the expander algorithm to least-waste
  susunola.tencentcloud.tke_cluster_autoscaler:
    region: ap-guangzhou
    cluster_id: cls-xxxxxxxx
    expander: least-waste
