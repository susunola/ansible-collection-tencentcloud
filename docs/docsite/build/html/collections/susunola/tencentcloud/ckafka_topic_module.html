susunola.tencentcloud.ckafka_topic module -- Manage Tencent Cloud CKafka topics

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.ckafka_topic.

New in susunola.tencentcloud 0.12.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

  • Return Values

Synopsis

  • Create, update and delete CKafka topics through the ckafka.v20190819 API.

  • This module is idempotent. Running it twice leaves the topic unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

Notes

Note

  • Requires the tencentcloud-sdk-python-ckafka package on the controller.

  • The CKafka instance itself is not created or destroyed by this module; provision it separately (e.g. in the console or with a postpaid instance request) to keep this module free of per-hour billing surprises.

Examples

- name: Create a topic with 3 partitions and 2 replicas
  susunola.tencentcloud.ckafka_topic:
    region: ap-guangzhou
    state: present
    instance_id: ckafka-xxxxxxxx
    topic_name: order-events
    partition_num: 3
    replica_num: 2
    retention_ms: 86400000
    note: Order event stream

- name: Scale partitions and update the note
  susunola.tencentcloud.ckafka_topic:
    region: ap-guangzhou
    state: present
    instance_id: ckafka-xxxxxxxx
    topic_name: order-events
    partition_num: 6
    note: Order event stream (scaled)

- name: Delete a topic
  susunola.tencentcloud.ckafka_topic:
    region: ap-guangzhou
    state: absent
    instance_id: ckafka-xxxxxxxx
    topic_name: order-events
