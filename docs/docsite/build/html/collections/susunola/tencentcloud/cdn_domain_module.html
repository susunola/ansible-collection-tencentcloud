susunola.tencentcloud.cdn_domain module -- Manage Tencent Cloud CDN domains

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.cdn_domain.

New in susunola.tencentcloud 0.13.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

  • Return Values

Synopsis

  • Add, start, stop and delete Tencent Cloud CDN acceleration domains through the cdn.v20180606 API.

  • This module is idempotent. Running it twice leaves the domain unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

  • A domain is identified by its domain name. Origin, service type, project and acceleration area are reconciled on existing domains.

Parameters

Parameter

Comments

area

string

Acceleration area, written to AddCdnDomainRequest.Area.

mainland accelerates in mainland China, overseas outside, global everywhere.

Updated on existing domains when supplied.

Choices:

  • "mainland"

  • "overseas"

  • "global"

backup_origins

list / elements=string

Backup origin addresses, written to Origin.BackupOrigins.

Updated on existing domains when supplied.

domain

string

Domain name to accelerate, e.g. cdn.example.com, written to AddCdnDomainRequest.Domain.

Required.

endpoint

string

Override the Tencent Cloud API endpoint.

origin_protocol

string

Protocol used when pulling from the origin, written to Origin.OriginPullProtocol.

http and https force the protocol, follow follows the client request.

  • "https"

  • "follow"

string

Notes

Note

  • Requires the tencentcloud-sdk-python-cdn package on the controller.

  • The domain must be owned and the origin must be reachable before AddCdnDomain succeeds.

  • state=absent deletes the domain configuration; the domain can be re-added afterwards.

Examples

- name: Add a CDN domain with a domain origin
  susunola.tencentcloud.cdn_domain:
    region: ap-guangzhou
    state: present
    domain: cdn.example.com
    service_type: web
    origins:
      - origin.example.com
    origin_type: domain
    origin_protocol: http

- name: Stop the domain
  susunola.tencentcloud.cdn_domain:
    region: ap-guangzhou
    state: stopped
    domain: cdn.example.com

- name: Start it again
  susunola.tencentcloud.cdn_domain:
    region: ap-guangzhou
    state: running
    domain: cdn.example.com

- name: Delete the domain
  susunola.tencentcloud.cdn_domain:
    region: ap-guangzhou
    state: absent
    domain: cdn.example.com
