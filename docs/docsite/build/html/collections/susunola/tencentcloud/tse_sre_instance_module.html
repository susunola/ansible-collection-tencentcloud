susunola.tencentcloud.tse_sre_instance module – Manage Tencent Cloud TSE service registry engines

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.tse_sre_instance.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Examples

  • Return Values

Synopsis

  • Creates and deletes TSE registry engines and reconciles client internet access for Nacos, Zookeeper, Consul, Apollo, Eureka and Polaris.
