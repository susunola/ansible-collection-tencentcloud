susunola.tencentcloud.cos_object_sync module – Mirror a local directory tree into a Tencent Cloud COS bucket

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.cos_object_sync.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

Synopsis

  • Synchronise a local directory tree into a Tencent Cloud Object Storage (COS) bucket prefix, uploading files that are new or changed and optionally deleting remote objects that no longer exist locally.

  • COS is not part of the Tencent Cloud API 3.0 family; this module uses the qcloud_cos SDK (cos-python-sdk-v5 package) instead.

  • This module is idempotent. A second run with an unchanged tree reports changed=false.

  • Upload change detection compares each local file’s MD5 digest against the remote object’s ETag, which is exact for single-part uploads.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

appid

string

Tencent Cloud account AppId used as the bucket name suffix.

When omitted, the AppId is resolved via the STS GetCallerIdentity API, which additionally requires the tencentcloud-sdk-python-sts package.

bucket

string / required

Bucket name, with or without the -<appid> suffix, for example mybucket or mybucket-1300000000.

The module appends the account AppId to a short name to form the full bucket name <name>-<appid> that the COS API expects.

delete

boolean

Delete remote objects under prefix that have no corresponding local file.

When false (default), extra remote objects are left in place and the module reports them as skipped_remote.

Choices:

  • false ← (default)

  • true

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

force

boolean

Re-upload every local file even when its MD5 matches the remote ETag.

Choices:

  • false ← (default)

  • true

prefix

string

Bucket key prefix the local tree is mirrored under, for example assets/. The bucket prefix, not the module’s prefix option.

When omitted, the tree is mirrored at the bucket root.

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

Notes

Note

  • Requires the cos-python-sdk-v5 package on the controller.

  • role_arn is honoured; the temporary credentials obtained via STS AssumeRole additionally require the tencentcloud-sdk-python-sts package.

  • Files are uploaded with single-part put_object calls so the ETag comparison stays exact; very large files are better handled by a dedicated streaming module.

Examples

- name: Mirror a local tree into a bucket prefix
  susunola.tencentcloud.cos_object_sync:
    region: ap-guangzhou
    bucket: mybucket
    appid: "1300000000"
    src: /var/www/assets
    prefix: assets/

- name: Mirror and delete remote objects that no longer exist locally
  susunola.tencentcloud.cos_object_sync:
    region: ap-guangzhou
    bucket: mybucket
    appid: "1300000000"
    src: /var/www/assets
    prefix: assets/
    delete: true

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

changed

boolean

Whether any object was uploaded or deleted.

Returned: always

deleted

list / elements=string

Object keys deleted by this run.

Returned: always

summary

dictionary

Counts of uploads and deletions performed, and objects skipped because they were unchanged or left in place when delete=false.

Returned: always

Sample: {"deleted": 0, "skipped_remote": 2, "unchanged": 12, "uploaded": 3}

uploaded

list / elements=string

Object keys uploaded by this run.

Returned: always
