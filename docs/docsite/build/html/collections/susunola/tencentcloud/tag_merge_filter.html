susunola.tencentcloud.tag_merge filter – Merge Tencent Cloud tag sources into one mapping

Note

This filter plugin is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.tag_merge.

New in susunola.tencentcloud 1.2.0

  • Synopsis

  • Input

  • Positional parameters

  • Examples

Synopsis

  • Merges any number of tag sources into a single mapping of key to value, with later sources overriding earlier ones.

  • Accepts every tag shape this collection already deals with, so the tags parameter of a resource module can be combined with the tags an *_info module reported without converting either side first.

  • The result is sorted by key and holds string values, which is what the resource modules compute for their tags parameter, so the result can be passed straight back into a module or compared against one.

Input

This describes the input of the filter, the value before | susunola.tencentcloud.tag_merge.

Parameter

Comments

Input

any

The first tag source.

Accepts a dict tag mapping, a single Key/Value tag, a list of tags, a list of SDK Tag objects, a nested list of any of those, or None for no tags at all.

May be omitted, which is how a list of sources is merged without naming any of them.

Positional parameters

This describes positional parameters of the filter. These are the values positional1, positional2 and so on in the following example: input | susunola.tencentcloud.tag_merge(positional1, positional2, ...)

Parameter

Comments

_additional

any

Further tag sources, merged left to right after the first. The last source that sets a key wins, matching dict.update and ansible.builtin.combine.

A source of an unsupported type (a string, a number) fails the task instead of being skipped, so a tag is never dropped silently.

Examples

- name: Read the tags an instance already carries
  susunola.tencentcloud.cvm_instance_info:
    instance_ids:
      - ins-xxxxxxxx
  register: cvm

- name: Add the environment tags without losing the instance's own tags
  vars:
    env_tags:
      environment: production
      owner: platform-team
  ansible.builtin.set_fact:
    instance_tags: "{{ cvm.instances[0].Tags | susunola.tencentcloud.tag_merge(env_tags) }}"

- name: Merge a list of sources in a single expression
  vars:
    common_tags:
      managed_by: ansible
    local_tags:
      environment: production
  ansible.builtin.debug:
    msg: "{{ [common_tags, cvm.instances[0].Tags, local_tags] | susunola.tencentcloud.tag_merge }}"

- name: A variable that may be unset contributes nothing
  ansible.builtin.debug:
    msg: "{{ extra_tags | default({}) | susunola.tencentcloud.tag_merge({'managed_by': 'ansible'}) }}"

Return Value

Key

Description

Return value

dictionary

The merged tags, sorted by key, with every key and value coerced to a string.

Returned: success
