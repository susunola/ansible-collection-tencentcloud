susunola.tencentcloud.clb_load_balancer module -- Manage Tencent Cloud CLB load balancers

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.clb_load_balancer.

New in susunola.tencentcloud 0.10.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

Synopsis

  • Create, update, and delete Tencent Cloud CLB (Cloud Load Balancer) instances through the clb.v20180317 API.

  • This module is idempotent. Running it twice leaves the load balancer unchanged and the second run reports changed=false. When load_balancer_id is not given, the instance is matched by the exact name (and vpc_id when given) from the fuzzy DescribeLoadBalancers result set.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

client_token

string

Idempotency token passed to CreateLoadBalancer as ClientToken, so a retried creation does not provision a second instance.

Only applied at creation; the value is not sensitive.

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

internet_charge_type

string

Network billing mode written to InternetAccessible.InternetChargeType.

On an existing instance the value is reconciled through ModifyLoadBalancerAttributes.

Choices:

  • "BANDWIDTH_PREPAID"

  • "TRAFFIC_POSTPAID_BY_HOUR"

  • "BANDWIDTH_POSTPAID_BY_HOUR"

  • "BANDWIDTH_PACKAGE"

internet_max_bandwidth_out

integer

Maximum outbound bandwidth in Mbps, written to InternetAccessible.InternetMaxBandwidthOut.

On an existing instance the value is reconciled through ModifyLoadBalancerAttributes.

load_balancer_id

string

ID of an existing load balancer, e.g. lb-xxxxxxxx.

When given, the module operates on that instance; otherwise the instance is matched by name through DescribeLoadBalancers.

load_balancer_type

string

Network type of the load balancer, OPEN for public or INTERNAL for private.

Only applied at creation; changing it on an existing instance fails with a message asking to recreate the load balancer.

Choices:

  • "OPEN"

  • "INTERNAL"

name

string

Name of the load balancer. Required when state=present.

DescribeLoadBalancers matches names fuzzily; the module filters the result for an exact name match before acting.

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

project_id

integer

Project ID the load balancer belongs to. Only applied at creation; changing it after creation is a no-op.

Default: 0

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

retries

integer

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

Default: 5

role_arn

string

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

role_session_duration

integer

Validity of the temporary role credentials in seconds.

Default: 7200

role_session_name

string

Session name recorded for the assumed role.

Default: "ansible-tencentcloud"

secret_id

string

Tencent Cloud API secret ID.

Falls back to TENCENTCLOUD_SECRET_ID, then to the selected profile section in ~/.tencentcloud/default.configure.

secret_key

string

Tencent Cloud API secret key.

Falls back to TENCENTCLOUD_SECRET_KEY, then to the selected profile section in ~/.tencentcloud/default.configure.

state

string

present creates the load balancer with CreateLoadBalancer when it does not exist, and updates its name, network billing and tags when it does.

absent deletes the load balancer with DeleteLoadBalancer and waits until it is gone.

Choices:

  • "present" ← (default)

  • "absent"

subnet_id

string

Subnet ID (subnet-xxxxxxxx) the VIP of a private load balancer is allocated from. Required by the API when creating an INTERNAL load balancer.

Only applied at creation; changing it on an existing instance fails with a message asking to recreate the load balancer.

tags

dictionary

Tags to apply to the load balancer as a dict, for example env=prod.

At creation the tags are bound through CreateLoadBalancer; on an existing instance they are reconciled through the tag service (ServiceType=clb, ResourcePrefix=clb).

Existing tags not listed are removed; listed tags with a different value are updated. Requires the tencentcloud-sdk-python-tag package and the tag service to be enabled for the account.

Default: {}

timeout

integer

SDK HTTP request timeout in seconds.

Default: 60

token

string

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

user_agent

string

Value appended to the SDK User-Agent header so API usage can be attributed to this collection.

Default: "ansible-collection.susunola.tencentcloud"

vpc_id

string

VPC ID (vpc-xxxxxxxx) the load balancer belongs to.

Only applied at creation; changing it on an existing instance fails with a message asking to recreate the load balancer.

Also used to disambiguate the name match when load_balancer_id is not given.

waiter_delay

integer

Interval in seconds between state polls while waiting.

Default: 5

waiter_timeout

integer

Maximum time in seconds to wait for the load balancer to reach the running state after creation, or to disappear after deletion.

Default: 120

Notes

Note

  • Requires the tencentcloud-sdk-python-clb package on the controller.

  • Tag reconciliation additionally requires tencentcloud-sdk-python-tag.

  • Uses the clb.tencentcloudapi.com endpoint by default.

  • CLB operations are asynchronous. After creation the module polls DescribeLoadBalancers until the instance Status is 1 (running), and ModifyLoadBalancerAttributes is confirmed through DescribeTaskStatus.

  • Network type, VPC and subnet cannot be changed on an existing load balancer; the module fails with a clear message when they drift instead of silently ignoring them.

Examples

- name: Create a public CLB load balancer
  susunola.tencentcloud.clb_load_balancer:
    region: ap-guangzhou
    state: present
    name: web-lb
    load_balancer_type: OPEN
    vpc_id: vpc-xxxxxxxx
    internet_charge_type: TRAFFIC_POSTPAID_BY_HOUR
    internet_max_bandwidth_out: 10
    tags:
      env: prod
      tier: web

- name: Create a private CLB load balancer
  susunola.tencentcloud.clb_load_balancer:
    region: ap-guangzhou
    state: present
    name: internal-lb
    load_balancer_type: INTERNAL
    vpc_id: vpc-xxxxxxxx
    subnet_id: subnet-xxxxxxxx

- name: Preview the changes without applying them
  susunola.tencentcloud.clb_load_balancer:
    region: ap-guangzhou
    state: present
    name: web-lb
    load_balancer_type: OPEN
  check_mode: true

- name: Delete a load balancer
  susunola.tencentcloud.clb_load_balancer:
    region: ap-guangzhou
    state: absent
    name: web-lb
