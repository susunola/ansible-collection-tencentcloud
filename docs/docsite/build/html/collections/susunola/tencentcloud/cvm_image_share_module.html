susunola.tencentcloud.cvm_image_share module – Manage Tencent Cloud CVM image sharing permissions

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.cvm_image_share.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

Synopsis

  • Share a custom CVM image with other Tencent Cloud accounts, or cancel existing shares, through the cvm.v20170312 API.

  • This module is idempotent. Running it twice leaves the share list unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

account_ids

list / elements=string / required

Root account IDs to share the image with, e.g. 103849387508. An account ID is different from a QQ number.

A custom image can be shared with at most 500 accounts, and sharing is only supported with accounts in the same region.

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

image_id

string / required

ID of the custom image, e.g. img-xxxxxxxx. The image must be in the NORMAL state.

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

Notes

Note

  • Requires the tencentcloud-sdk-python-cvm package on the controller.

  • Only account-level sharing is managed; global sharing (every account) is not supported by this module.

  • Sharing with your own account fails with a platform error.

Examples

- name: Share an image with two accounts
  susunola.tencentcloud.cvm_image_share:
    region: ap-guangzhou
    state: present
    image_id: img-xxxxxxxx
    account_ids:
      - "100000000001"
      - "100000000002"

- name: Stop sharing with one account
  susunola.tencentcloud.cvm_image_share:
    region: ap-guangzhou
    state: absent
    image_id: img-xxxxxxxx
    account_ids:
      - "100000000001"
