susunola.tencentcloud.dlc_table_partition module -- Manage Tencent Cloud DLC table partition entries

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.dlc_table_partition.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Examples

  • Return Values

Synopsis

  • Creates, updates and drops exact DLC Data Management Service partition entries.

  • Partition values form the stable identity; parameters and storage descriptors are reconciled semantically.

Examples

- susunola.tencentcloud.dlc_table_partition:
    database_name: analytics
    table_name: daily_sales
    values: ['2026-08-31']
    name: sale_date=2026-08-31
    params: {source: batch}
    storage:
      location: cosn://analytics-bucket/daily_sales/sale_date=2026-08-31/

- susunola.tencentcloud.dlc_table_partition:
    database_name: analytics
    table_name: daily_sales
    values: ['2026-08-31']
    state: absent
    allow_delete: true
