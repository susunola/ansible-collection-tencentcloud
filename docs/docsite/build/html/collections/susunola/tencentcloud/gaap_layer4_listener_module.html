susunola.tencentcloud.gaap_layer4_listener module -- Manage Tencent Cloud GAAP TCP and UDP listeners

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.gaap_layer4_listener.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Examples

  • Return Values

Synopsis

  • Creates, updates and deletes one idempotent GAAP layer-4 listener on a proxy or proxy group.
