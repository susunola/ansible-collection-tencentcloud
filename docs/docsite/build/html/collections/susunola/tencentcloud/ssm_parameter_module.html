susunola.tencentcloud.ssm_parameter module -- Manage Tencent Cloud SSM secrets (parameters)

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.ssm_parameter.

New in susunola.tencentcloud 0.12.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

  • Return Values

Synopsis

  • Create, update and delete Tencent Cloud SSM secrets through the ssm.v20190923 API.

  • This compatibility module manages a secret and its current value. New playbooks should prefer ssm_secret with ssm_secret_version for explicit, immutable version management.

  • The supplied value is compared with the current value without returning it; an unchanged value reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

delete_mode

string

soft schedules the secret for deletion after recovery_window_in_days days (default 30, minimum 7), leaving it recoverable during that window.

immediate purges the secret immediately; it cannot be recovered.

Choices:

  • "soft" ← (default)

  • "immediate"

description

string

Optional description of the secret, written to CreateSecretRequest.Description.

encrypt_type

integer

Encryption type. 0 uses KMS encryption and 1 uses software-key encryption. kms_key_id selects a customer KMS key with 0.

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

kms_key_id

string

Customer master key ID when encrypt_type=0.

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

recovery_window_in_days

integer

Days to keep a soft-deleted secret before purging it, written to DeleteSecretRequest.RecoveryWindowInDays.

Default: 30

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

retries

integer

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

Default: 5

role_arn

string

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

role_session_duration

integer

Validity of the temporary role credentials in seconds.

Default: 7200

role_session_name

string

Session name recorded for the assumed role.

Default: "ansible-tencentcloud"

secret_binary

string

Base64-encoded binary value of the secret, written to CreateSecretRequest.SecretBinary.

Provide either secret_string or secret_binary, not both.

The value is treated as sensitive and never logged.

secret_id

string

Tencent Cloud API secret ID.

Falls back to TENCENTCLOUD_SECRET_ID, then to the selected profile section in ~/.tencentcloud/default.configure.

secret_key

string

Tencent Cloud API secret key.

Falls back to TENCENTCLOUD_SECRET_KEY, then to the selected profile section in ~/.tencentcloud/default.configure.

secret_name

string / required

Name of the secret, e.g. prod/db-password.

Required to identify, create, update or delete the secret.

secret_string

string

Plain-text value of the secret, written to CreateSecretRequest.SecretString and UpdateSecretRequest.

Provide either secret_string or secret_binary, not both.

The value is treated as sensitive and never logged.

secret_type

integer

Type of the secret. 0 is a generic secret, 1 an SSH key pair secret, 4 a Tencent Cloud credential secret.

Default: 0

state

string

present creates the secret when it does not exist and updates its value and description when it does.

absent deletes the secret. By default the secret is soft-deleted (recoverable) for 30 days; set delete_mode=immediate to purge it right away.

Choices:

  • "present" ← (default)

  • "absent"

tags

dictionary

Tags to apply to the secret as a dict, for example env=prod.

Only applied at creation.

Default: {}

timeout

integer

SDK HTTP request timeout in seconds.

Default: 60

token

string

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

user_agent

string

Value appended to the SDK User-Agent header so API usage can be attributed to this collection.

Default: "ansible-collection.susunola.tencentcloud"

waiter_delay

integer

Seconds to wait between state-polling attempts while waiting for a resource to reach its desired state.

Default: 5

waiter_timeout

integer

Overall timeout in seconds for state polling before the module gives up and fails the task.

Default: 120

Notes

Note

  • Requires the tencentcloud-sdk-python-ssm package on the controller.

  • Secret values are marked no_log=true and never appear in task output; the module compares values only when an update is requested.

  • Pair with the ``ssm_parameter`` lookup to consume values at play time without exposing them in inventories.

Examples

- name: Create a plain-text secret
  susunola.tencentcloud.ssm_parameter:
    region: ap-guangzhou
    state: present
    secret_name: prod/db-password
    secret_string: "{{ db_password }}"
    description: Database password for the production app

- name: Update the secret value (creates a new version)
  susunola.tencentcloud.ssm_parameter:
    region: ap-guangzhou
    state: present
    secret_name: prod/db-password
    secret_string: "{{ new_password }}"

- name: Soft-delete a secret (recoverable for 30 days)
  susunola.tencentcloud.ssm_parameter:
    region: ap-guangzhou
    state: absent
    secret_name: prod/db-password

- name: Purge a secret immediately
  susunola.tencentcloud.ssm_parameter:
    region: ap-guangzhou
    state: absent
    secret_name: prod/db-password
    delete_mode: immediate
