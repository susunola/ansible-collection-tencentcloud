susunola.tencentcloud.cos_object module -- Manage Tencent Cloud COS objects

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.cos_object.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

Synopsis

  • Upload, download, and delete Tencent Cloud Object Storage (COS) objects.

  • COS is not part of the Tencent Cloud API 3.0 family; this module uses the qcloud_cos SDK (cos-python-sdk-v5 package) instead.

  • This module is idempotent. Uploading the same content again reports changed=false, and deleting an absent object reports changed=false.

  • Upload compares the object ETag against the local MD5 digest; the ETag comparison is exact for single-part uploads. Metadata and storage-class drift also trigger a re-upload even when the content is unchanged.

  • Supports check mode; no API write happens in check mode, only reads.

Parameters

Parameter

Comments

appid

string

Tencent Cloud account AppId used as the bucket name suffix.

When omitted, the AppId is resolved via the STS GetCallerIdentity API, which additionally requires the tencentcloud-sdk-python-sts package.

bucket

string / required

Bucket name, with or without the -<appid> suffix, for example mybucket or mybucket-1300000000.

The module appends the account AppId to a short name to form the full bucket name <name>-<appid> that the COS API expects.

content

string

Inline string to upload as the object body.

Mutually exclusive with src.

dest

path

Local file path to download the object to.

Required when state=present and neither src nor content is given (the download form of the module).

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

expires

integer

Validity of the pre-signed URL in seconds when presign=true.

Default: 3600

force

boolean

When uploading, re-upload even when the remote ETag matches the local content.

When downloading, overwrite an existing local file even when its MD5 matches the remote ETag.

Choices:

  • false ← (default)

  • true

metadata

dictionary

User-defined object metadata as a dict; keys are sent as x-cos-meta-<key> headers. Replaced in full on upload.

Default: {}

method

string

HTTP method the pre-signed URL is signed for when presign=true; GET mints a download URL, PUT an upload URL.

Passing a non-default value with presign=false fails the task.

Choices:

  • "GET" ← (default)

  • "PUT"

object

string / required

Object key (the full path inside the bucket), for example images/logo.png.

presign

boolean

When true, do not transfer anything; instead return a pre-signed URL for the object as url, signed for the HTTP method. Nothing is read or written in the bucket and the task reports changed=false.

Only valid with state=present.

Choices:

  • false ← (default)

  • true

profile

string

added in susunola.tencentcloud 0.5.0

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

region

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

retries

integer

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

Default: 5

role_arn

string

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

role_session_duration

integer

Validity of the temporary role credentials in seconds.

Default: 7200

role_session_name

string

Session name recorded for the assumed role.

Default: "ansible-tencentcloud"

secret_id

string

Tencent Cloud API secret ID.

Falls back to TENCENTCLOUD_SECRET_ID, then to the selected profile section in ~/.tencentcloud/default.configure.

secret_key

string

Tencent Cloud API secret key.

Falls back to TENCENTCLOUD_SECRET_KEY, then to the selected profile section in ~/.tencentcloud/default.configure.

src

path

Local file path to upload to the object.

Mutually exclusive with content.

state

string

present uploads src/content to the object, or downloads the object to dest when neither src nor content is given.

absent deletes the object if it exists.

Choices:

  • "present" ← (default)

  • "absent"

storage_class

string

Storage class of the object, for example STANDARD, STANDARD_IA, INTELLIGENT_TIERING or ARCHIVE. Applied on upload.

Default: "STANDARD"

timeout

integer

SDK HTTP request timeout in seconds.

Default: 60

token

string

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

user_agent

string

Value appended to the SDK User-Agent header so API usage can be attributed to this collection.

Default: "ansible-collection.susunola.tencentcloud"

waiter_delay

integer

Seconds to wait between state-polling attempts while waiting for a resource to reach its desired state.

Default: 5

waiter_timeout

integer

Overall timeout in seconds for state polling before the module gives up and fails the task.

Default: 120

Notes

Note

  • Requires the cos-python-sdk-v5 package on the controller.

  • role_arn is honoured; the temporary credentials obtained via STS AssumeRole additionally require the tencentcloud-sdk-python-sts package.

Examples

- name: Upload a local file to COS
  susunola.tencentcloud.cos_object:
    region: ap-guangzhou
    state: present
    bucket: mybucket
    appid: "1300000000"
    object: images/logo.png
    src: /var/www/logo.png

- name: Upload inline content with metadata
  susunola.tencentcloud.cos_object:
    region: ap-guangzhou
    state: present
    bucket: mybucket
    appid: "1300000000"
    object: config.json
    content: "{\"env\": \"prod\"}"
    metadata:
      owner: platform
    storage_class: STANDARD_IA

- name: Download an object to a local path
  susunola.tencentcloud.cos_object:
    region: ap-guangzhou
    state: present
    bucket: mybucket
    appid: "1300000000"
    object: reports/daily.csv
    dest: /tmp/daily.csv

- name: Delete an object
  susunola.tencentcloud.cos_object:
    region: ap-guangzhou
    state: absent
    bucket: mybucket
    appid: "1300000000"
    object: images/logo.png

- name: Mint a short-lived pre-signed download URL
  susunola.tencentcloud.cos_object:
    region: ap-guangzhou
    state: present
    bucket: mybucket
    appid: "1300000000"
    object: reports/daily.csv
    presign: true
    method: GET
    expires: 600
  register: presigned

- name: Mint a short-lived pre-signed upload URL
  susunola.tencentcloud.cos_object:
    region: ap-guangzhou
    state: present
    bucket: mybucket
    appid: "1300000000"
    object: uploads/new-asset.zip
    presign: true
    method: PUT
  register: upload_url

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

object

dictionary

The object as reported by COS after the operation.

Returned: success

Sample: {"bucket": "mybucket-1300000000", "content_length": 11, "etag": "\"9f86d081884c7d659a2feaa0c55ad015\"", "key": "images/logo.png", "metadata": {"x-cos-meta-owner": "platform"}, "storage_class": "STANDARD"}

url

string

The pre-signed URL, signed with the module credentials.

Returned: when presign=true

Sample: "https://mybucket-1300000000.cos.ap-guangzhou.myqcloud.com/images/logo.png?q-sign-algorithm=sha1&..."
