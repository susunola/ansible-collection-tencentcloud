susunola.tencentcloud.tse_gateway_secret_key module – Manage a Tencent Cloud TSE API gateway secret key

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.tse_gateway_secret_key.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Examples

  • Return Values

Synopsis

  • Creates, enables, disables, rotates and deletes API gateway credentials.

  • Credential material is redacted from normal results. Set reveal_secret_value=true only when a protected downstream task must capture it.

  • Protocol and credential configuration changes require explicit destructive rotation.
