Susunola.Tencentcloud

Collection version 1.1.0

  • Description

  • Plugin Index

Description

Ansible modules and plugins for automating Tencent Cloud (QCloud) resources through Tencent Cloud API 3.0. 875 modules (resource modules plus _info facts modules) cover compute (CVM, Lighthouse, TKE), network (VPC, CLB, security groups), storage (COS, CBS), database (TencentDB, Redis, MongoDB), security and middleware services, with inventory, lookup and connection plugins and deployment roles.

Author:

  • Tencent Cloud Ansible Collection Contributors (@susunola)

Supported ansible-core versions:

  • 2.19.0 or newer
