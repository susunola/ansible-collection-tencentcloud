susunola.tencentcloud.ssm_parameter lookup -- Retrieve Tencent Cloud Secrets Manager secret values

Note

This lookup plugin is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.ssm_parameter.

New in susunola.tencentcloud 0.5.0

  • Synopsis

  • Keyword parameters

  • Notes

  • Examples

  • Return Value

Synopsis

  • Lookup terms are Tencent Cloud Secrets Manager (SSM) secret names; the current version (SSM_Current) of each secret is fetched with the GetSecretValue API and the plaintext payload is returned.

  • Terms containing = are parsed as keyword arguments, for example region=ap-guangzhou; all other terms are treated as secret names.

  • Tencent Cloud SSM is a secrets manager, not a parameter store; this lookup is the closest equivalent of the amazon.aws.aws_ssm lookup.

Keyword parameters

This describes keyword parameters of the lookup. These are the values key1=value1, key2=value2 and so on in the following examples: lookup('susunola.tencentcloud.ssm_parameter', key1=value1, key2=value2, ...) and query('susunola.tencentcloud.ssm_parameter', key1=value1, key2=value2, ...)

Parameter

Comments

profile

string

TCCLI credential profile section of ~/.tencentcloud/default.configure used as a fallback for region, secret_id and secret_key.

Explicit terms and their environment variables take precedence over the profile.

Falls back to TENCENTCLOUD_PROFILE.

Configuration:

  • Environment variable: TENCENTCLOUD_PROFILE

region

string / required

Tencent Cloud region hosting the secrets.

Falls back to TENCENTCLOUD_REGION.

Configuration:

  • Environment variable: TENCENTCLOUD_REGION

secret_id

string

Tencent Cloud API secret ID. Falls back to TENCENTCLOUD_SECRET_ID.

Configuration:

  • Environment variable: TENCENTCLOUD_SECRET_ID

secret_key

string

Tencent Cloud API secret key. Falls back to TENCENTCLOUD_SECRET_KEY.

Configuration:

  • Environment variable: TENCENTCLOUD_SECRET_KEY

token

string

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

Configuration:

  • Environment variable: TENCENTCLOUD_TOKEN

with_decryption

boolean

Accepted for parity with the amazon.aws.aws_ssm lookup.

GetSecretValue always returns the decrypted payload, so this option has no effect on the returned values.

Choices:

  • false

  • true ← (default)

Notes

Note

  • Requires the tencentcloud-sdk-python-ssm package on the controller.

Examples

- name: Look up a single secret
  ansible.builtin.debug:
    msg: "{{ lookup('susunola.tencentcloud.ssm_parameter', 'db-password', region='ap-guangzhou') }}"

- name: Look up several secrets at once
  ansible.builtin.debug:
    msg: >-
      {{ lookup('susunola.tencentcloud.ssm_parameter',
                'db-password', 'api-token',
                'region=ap-guangzhou') }}

Return Value

Key

Description

Return value

list / elements=string

List of secret payloads, one per requested secret name, in term order.

Text secrets yield their SecretString value; binary secrets yield the base64-encoded SecretBinary value.

Returned: success
