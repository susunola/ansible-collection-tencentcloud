susunola.tencentcloud.cbs_disk module -- Manage Tencent Cloud CBS cloud disks

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.cbs_disk.

New in susunola.tencentcloud 0.12.0

  • Synopsis

  • Parameters

  • Notes

  • Examples

  • Return Values

Synopsis

  • Create, resize, attach, detach and delete CBS cloud disks through the cbs.v20170312 API.

  • This module is idempotent. Running it twice leaves the disk unchanged and the second run reports changed=false.

  • Supports check mode; no API write happens in check mode, only reads.

  • Attachment changes wait for the disk to reach the target state (ATTACHED/UNATTACHED) using waiter_delay and waiter_timeout.

Parameters

Parameter

Comments

charge_type

string

Billing mode of the disk, written to CreateDisksRequest.DiskChargeType.

Only applied at creation.

Choices:

  • "PREPAID"

  • "POSTPAID_BY_HOUR" ← (default)

delete_snapshot

boolean

Delete snapshots of the disk together with the disk, written to TerminateDisksRequest.DeleteSnapshot.

Choices:

  • false ← (default)

  • true

delete_with_instance

boolean

When true, the disk is deleted together with the instance it is attached to, written to AttachDisksRequest.DeleteWithInstance.

Choices:

  • false

  • true

detach

boolean

When true and the disk is attached, the disk is detached and waited into UNATTACHED state.

Mutually exclusive with instance_id in effect; when both are given instance_id wins.

Choices:

  • false ← (default)

  • true

disk_id

string

ID of an existing disk, e.g. disk-xxxxxxxx.

When given, the module operates on that disk; otherwise the disk is matched by name (optionally scoped by zone).

disk_size

integer

Capacity of the disk in GiB, written to CreateDisksRequest.DiskSize.

When the disk exists and disk_size is larger than the current size, the disk is resized with ResizeDisk (resize only grows, never shrinks).

disk_type

string

Media type of the disk, written to CreateDisksRequest.DiskType.

Only applied at creation.

Choices:

  • "CLOUD_BASIC"

  • "CLOUD_PREMIUM"

  • "CLOUD_SSD"

  • "CLOUD_HSSD"

  • "CLOUD_TSSD"

encrypt

boolean

Encrypt the disk at creation, written to CreateDisksRequest.Encrypt.

Only applied at creation.

Choices:

  • false

  • true

endpoint

string

Override the Tencent Cloud API endpoint.

Intended for private endpoints, proxies, and integration tests.

instance_id

string

ID of the CVM instance to attach the disk to, e.g. ins-xxxxxxxx, written to AttachDisksRequest.InstanceId.

When given and the disk is attached elsewhere, the disk is detached first, then attached and waited into ATTACHED state.

name

string

Name of the disk, written to CreateDisksRequest.DiskName and ModifyDiskAttributesRequest.DiskName.

prepaid_period_months

integer

Prepaid period in months, written to CreateDisksRequest.DiskChargePrepaid.Period.

Only applied when charge_type=PREPAID.

Name of the TCCLI profile section in ~/.tencentcloud/default.configure to read credentials and region from, for example default or prod.

A profile only supplies values not given as module parameters or environment variables; precedence is parameter > environment variable > profile section.

Falls back to TENCENTCLOUD_PROFILE; when neither is set the default section is used.

string

Tencent Cloud region.

Falls back to TENCENTCLOUD_REGION, then to the region key of the selected profile section in ~/.tencentcloud/default.configure.

Required unless one of those fallbacks provides it.

Number of retries for transient SDK failures, applied with exponential backoff before the module gives up.

CAM role ARN to assume via the STS AssumeRole API before calling any other service, for example qcs::cam::uin/1000000000:roleName/MyRole.

When set, the module exchanges secret_id/secret_key for temporary credentials bound to this role.

Falls back to TENCENTCLOUD_ROLE_ARN.

Validity of the temporary role credentials in seconds.

Default: 7200

Session name recorded for the assumed role.

string

Tencent Cloud API secret ID.

Tencent Cloud API secret key.

Create the disk from this snapshot, written to CreateDisksRequest.SnapshotId.

Only applied at creation.

string

absent terminates the disk.

Choices:

  • "present" ← (default)

  • "absent"

dictionary

Tags to apply to the disk as a dict, for example env=prod.

Only applied at creation.

Default: {}

integer

SDK HTTP request timeout in seconds.

Availability zone of the disk, e.g. ap-guangzhou-3.

Required when creating the disk and used to narrow name matches.

Notes

Note

  • Requires the tencentcloud-sdk-python-cbs package on the controller.

  • POSTPAID_BY_HOUR disks are billed per hour while present; terminate them as soon as they are no longer needed to avoid unnecessary charges.

Examples

- name: Create a 50 GiB SSD disk
  susunola.tencentcloud.cbs_disk:
    region: ap-guangzhou
    state: present
    name: data-disk
    zone: ap-guangzhou-3
    disk_type: CLOUD_SSD
    disk_size: 50
    tags:
      env: prod

- name: Attach it to an instance and wait until ATTACHED
  susunola.tencentcloud.cbs_disk:
    region: ap-guangzhou
    state: present
    name: data-disk
    zone: ap-guangzhou-3
    instance_id: ins-aaaaaaaa
    delete_with_instance: false

- name: Detach and wait until UNATTACHED
  susunola.tencentcloud.cbs_disk:
    region: ap-guangzhou
    state: present
    name: data-disk
    zone: ap-guangzhou-3
    detach: true

- name: Grow the disk to 100 GiB
  susunola.tencentcloud.cbs_disk:
    region: ap-guangzhou
    state: present
    name: data-disk
    zone: ap-guangzhou-3
    disk_size: 100

- name: Terminate the disk
  susunola.tencentcloud.cbs_disk:
    region: ap-guangzhou
    state: absent
    name: data-disk
    zone: ap-guangzhou-3
