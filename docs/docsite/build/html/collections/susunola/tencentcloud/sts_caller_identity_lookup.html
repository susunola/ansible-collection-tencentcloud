susunola.tencentcloud.sts_caller_identity lookup – Get information about the Tencent Cloud credentials in use

Note

This lookup plugin is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.sts_caller_identity.

New in susunola.tencentcloud 0.5.0

  • Synopsis

  • Keyword parameters

  • Notes

  • Examples

  • Return Value

Synopsis

  • Calls the Tencent Cloud STS GetCallerIdentity API and returns the account and identity the current credentials belong to.

  • Lookup terms only carry keyword arguments, for example secret_id=... region=....

Keyword parameters

This describes keyword parameters of the lookup. These are the values key1=value1, key2=value2 and so on in the following examples: lookup('susunola.tencentcloud.sts_caller_identity', key1=value1, key2=value2, ...) and query('susunola.tencentcloud.sts_caller_identity', key1=value1, key2=value2, ...)

Parameter

Comments

profile

string

TCCLI credential profile section of ~/.tencentcloud/default.configure used as a fallback for secret_id and secret_key.

Explicit terms and their environment variables take precedence over the profile.

Falls back to TENCENTCLOUD_PROFILE.

Configuration:

  • Environment variable: TENCENTCLOUD_PROFILE

region

string

Region used for the STS endpoint. Falls back to TENCENTCLOUD_REGION.

STS is a global service; the region only selects the access point.

Configuration:

  • Environment variable: TENCENTCLOUD_REGION

role_arn

string

When set, assume this CAM role with AssumeRole before calling GetCallerIdentity, so the returned identity is the assumed role.

Falls back to TENCENTCLOUD_ROLE_ARN.

Configuration:

  • Environment variable: TENCENTCLOUD_ROLE_ARN

secret_id

string

Tencent Cloud API secret ID. Falls back to TENCENTCLOUD_SECRET_ID.

Configuration:

  • Environment variable: TENCENTCLOUD_SECRET_ID

secret_key

string

Tencent Cloud API secret key. Falls back to TENCENTCLOUD_SECRET_KEY.

Configuration:

  • Environment variable: TENCENTCLOUD_SECRET_KEY

token

string

Temporary credential token. Falls back to TENCENTCLOUD_TOKEN.

Configuration:

  • Environment variable: TENCENTCLOUD_TOKEN

Notes

Note

  • Requires the tencentcloud-sdk-python-sts package on the controller.

Examples

- name: Show the caller identity
  ansible.builtin.debug:
    msg: "{{ lookup('susunola.tencentcloud.sts_caller_identity') }}"

- name: Identity of an assumed role in a specific region
  ansible.builtin.debug:
    msg: >-
      {{ lookup('susunola.tencentcloud.sts_caller_identity',
                'region=ap-guangzhou',
                'role_arn=qcs::cam::uin/100000000001:roleName/ops') }}

Return Value

Key

Description

Return value

list / elements=dictionary

A one-element list holding a dict with the caller identity.

Keys mirror the GetCallerIdentity response fields, for example AccountId, Arn, PrincipalId, Type and UserId.

Returned: success
