susunola.tencentcloud.cdwch_instance module -- Manage Tencent Cloud TCHouse-C instances

Note

This module is part of the susunola.tencentcloud collection (version 1.1.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install susunola.tencentcloud.

To use it in a playbook, specify: susunola.tencentcloud.cdwch_instance.

New in susunola.tencentcloud 0.14.0

  • Synopsis

  • Parameters

  • Examples

  • Return Values

Synopsis

  • Creates and destroys TCHouse-C instances and reconciles ClickHouse and ZooKeeper node count, specification and disk capacity.
