# Code of Conduct

This collection follows the [Ansible Community Code of Conduct](https://docs.ansible.com/ansible/latest/community/code_of_conduct.html).

If you believe someone is violating the Code of Conduct, we ask that you
report it by emailing the Ansible Code of Conduct Committee at
`conduct@ansible.com`. For more information, please refer to the
[Ansible Code of Conduct page](https://docs.ansible.com/ansible/latest/community/code_of_conduct.html).

All discussion channels, issue trackers, pull requests, and contributions to
this collection are covered by the Code of Conduct.
